# Хроники Подземелий — прототип

Текстовая RPG с ИИ-мастером в духе «Подземелий и драконов» (правила SRD 5.2, упрощённо). Игрок пишет, что делает герой, а дальше работают три участника:

- **арбитр** (ИИ) переводит заявку в механику;
- **движок правил** (код) бросает кубы и меняет состояние;
- **рассказчик** (ИИ) описывает результат и предлагает варианты.

Прототип состоит из сервера и веб-клиента, в который можно играть с телефона через браузер. Подробности в GDD в проекте «Мобильная игра».

## Запуск на Windows

1. Положите папку проекта рядом с `dm-model-test`. Тогда ключи подхватятся из `dm-model-test\keys.bat` сами. Другой вариант: впишите их в `.env`, он создаётся из `.env.example` при первом запуске.
2. Дважды щёлкните **`start.bat`**. Если Node.js нет, файл установит его через winget.
3. Откройте адрес из окна:
   - на компьютере: `http://localhost:8080`;
   - с телефона: `http://192.168.x.x:8080`. Телефон должен быть в той же Wi-Fi сети.

   Если Windows спросит про брандмауэр, разрешите доступ в **частных сетях**.

Без ключей сервер запускается с **заглушкой ИИ**: правила по ключевым словам, ноль расходов. Чтобы включить заглушку принудительно, поставьте `AI_MODE=mock` в `.env`.

Тесты запускаются через `test.bat` или `npm test`.

## Что есть в прототипе

- Кампания «Логово гоблинов»: 9 локаций, ~10 врагов, 3 развязки. Герои: воин, плут, волшебник, жрец (1 уровень).
- Ход игрока проходит так:
  1. фильтр заявки;
  2. арбитр;
  3. серверный страж;
  4. движок;
  5. рассказчик.
- Страж по GDD 4.1 проверяет:
  - золото и предметы;
  - ячейки заклинаний;
  - урон оружия по таблице;
  - СЛ атаки, которая равна КД цели;
  - выходы и подбор предметов только из локации.
- Битый JSON от модели обрабатывается так: один повтор, потом запасной вариант. Ход не теряется.
- Энергия: 1 ход стоит 1 ⚡, каждый день +30. «Реклама» (+5, до 5 раз в день) и «покупка» (+50) пока заглушки.
- Отдых: в деревне и таверне полный, в пути короткий привал.
- В меню «Расходы на ИИ» видно рубли за ход и время ответа. Лог всех ходов пишется в `data/logs/turns.jsonl`.

## Устройство

```
src/
  types.ts            общие типы
  config.ts           настройки из .env
  data/               справочники SRD, герои, кампания
  engine/             кубы, фильтр заявки, страж, разрешение хода (без ИИ)
  ai/                 клиент Яндекса, заглушка, сборка контекста, проверка JSON, схемы
  game/               ход целиком, сохранения
  server.ts           HTTP API и раздача клиента
prompts/              системные промпты арбитра и рассказчика
public/               веб-клиент (HTML/CSS/JS без сборки)
tests/                node:test
```

Внешних зависимостей нет: TypeScript запускается самим Node.js (≥ 22.18), а HTTP и `fetch` встроенные.

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/meta` | герои и режим ИИ |
| POST | `/api/games` `{preset, name}` | новая игра |
| GET | `/api/games/:id` | состояние |
| POST | `/api/games/:id/turn` `{action}` | ход |
| POST | `/api/games/:id/energy` `{source: ad\|purchase}` | энергия (заглушка) |
| GET | `/api/stats` | расходы и качество ответов ИИ |
